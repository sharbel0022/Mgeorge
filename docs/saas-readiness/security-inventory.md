## Explicit gaps and assumptions

- **Browser execution:** no comprehensive stored-XSS campaign across all pages, attributes, URL sinks and uploaded content was run in this review. Existing Node VM and React static-markup tests provide useful bounded evidence.
- **Raw style sink:** `sites/components/ui/chart.tsx` uses `dangerouslySetInnerHTML` to build CSS from chart configuration. No consumer or untrusted-data path was found across the 37 inspected non-UI app/component files. Its ID/config/color inputs must remain developer-controlled; the review does not claim the repository has no raw HTML sinks.
- **Deployed headers:** Node's page CSP and both original-download policies are visible in application source. No global Sites page-CSP declaration was found in the inspected `sites/next.config.ts` or `sites/app/layout.tsx`. Effective platform/proxy response headers need deployment evidence.
- **Trusted ingress and egress:** `sites/app/chatgpt-auth.ts` relies on platform `oai-authenticated-*` headers. Host/TLS routing, header stripping, proxy policy, DNS and network egress controls were not tested against a deployed service.
- **Scope:** test existence and CI inclusion are distinct from a passing release run. Refer to the final revision's full CI receipts; the focused 104-test GREEN result in the tenant report is not the total coverage of this inventory.
